# Changelog

## v1.0.0 - 2026-09-20

### Included

- Standalone 64-bit Windows portable application
- PyQt desktop HUD with floating animated avatar
- Gemini Live voice interaction and typed commands
- Persistent memory and session summaries
- Computer, browser, file, desktop, reminder, weather, flight, and game tools
- Screen and webcam analysis
- Hardware monitoring and reactive audio visualization
- Assistant customization, modes, voices, themes, and audio-device selection
- Optional phone dashboard with local pairing and encrypted session traffic

### Distribution

- `Jarvis-Windows-x64-v1.0.0.zip`
- No Python runtime or development tools required
- API credentials are entered locally on first launch and are not bundled
